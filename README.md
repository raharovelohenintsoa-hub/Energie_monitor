# Energie_monitor
AI-powered electricity consumption analysis, forecasting, and anomaly detection.

 Energie Monitor — AI Project

 Description

Energie Monitor is a Python-based project designed to analyze electricity consumption, predict future energy usage, and detect unusual consumption patterns using machine learning.

#Objectives

- Analyze electricity consumption data.
- Predict future energy consumption.
- Detect abnormal electricity usage.
- Build an interactive dashboard for data visualization.

#Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit
